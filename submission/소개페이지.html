가족의 생존 기록

전쟁으로 떨어진 가족이 영상과 음성을 남깁니다. 작성자와 기록 시각을 확인하고, 연결이 복구되면 공유합니다.

영상 3초 · 음성 최대 10초

실행 방법 보기박현준 실행 방법 알려줘계획서 읽기

통화하기 어려운 가족

전쟁과 피란으로 떨어진 가족은 같은 시간에 접속하기 어렵습니다. 연결이 끊긴 동안에는 안부를 전할 수 없습니다.

가족이 직접 남긴 영상과 음성을 날짜별로 모읍니다. 수신자는 작성 시각을 확인하고, 가능한 시간에 재생합니다.

기록은 남긴 당시의 정보입니다. 현재의 생존 여부나 안전을 자동으로 판정하지 않습니다.

시연 범위: 가족 공간 1개, 가족 계정 2개, 등록 거주지 1곳

기록과 공유

촬영·녹음 후 먼저 재생해 봅니다. 버리기, 다시 기록하기, 기기에 보관, 가족과 공유 중에서 선택합니다.

저장과 공유를 선택하기 전에는 기기에 기록을 보관하지 않습니다.

  1. 촬영하거나 녹음하기

    영상은 3초, 음성은 최대 10초에 자동으로 끝납니다.

  2. 먼저 보고 듣기

    결정 전 기록은 임시 메모리에만 있습니다. 창을 닫으면 사라집니다.

  3. 남길 곳 선택하기

    기기에만 보관하거나, 가족과 공유합니다. 버리기를 선택하면 저장하지 않습니다.

공유한 뒤에도 작성자는 자기 기록을 삭제할 수 있습니다. 다른 가족의 기록은 삭제할 수 없습니다.

통신이 끊겼을 때

처음 접속하고 가족 공간에 가입한 뒤에는 오프라인에서도 기록할 수 있습니다. 공유를 선택한 기록은 기기에 보관되며 업로드 대기로 표시됩니다.

연결을 복구한 뒤 앱을 열어 두거나 다시 열면 업로드합니다. 인터넷이 끊긴 동안 다른 기기로 즉시 전달하는 기능은 포함하지 않습니다.

작성 시각 유지

월요일에 녹음한 음성을 수요일에 올려도 월요일 기록으로 표시합니다. 업로드한 시각과 기록한 시각을 구분합니다.

기기에만 저장

보관만 선택한 기록은 자동으로 공유하지 않습니다. 나중에 확인한 뒤 공유할 수 있습니다.

오프라인 삭제

기기에서 먼저 지우고, 작성자 계정으로 연결되면 서버에도 반영합니다. 이미 내려받은 사본은 그대로 남습니다.

기간별 파일 내보내기

시작일과 종료일을 고르면 촬영·녹음 시각순으로 묶습니다.

포함할 수 있는 기록과 업로드를 기다리는 기록의 개수를 먼저 확인합니다.

MP4
영상만 잇거나 영상과 음성을 함께 담습니다. 음성 구간에는 날짜와 작성자 이름을 표시합니다.
M4A
음성 기록을 하나로 이어 듣습니다. 개별 녹음도 내려받을 수 있습니다.
TXT
작성자와 녹음 시각을 붙인 음성 인식 결과입니다. 잘못 인식한 글은 수정할 수 있습니다.
ZIP
영상, 음성, 텍스트를 함께 내려받습니다.

집 주변 관측 자료

가자지구 알샤티의 두 시점 자료를 보여줍니다. 관측일과 출처를 붙이고, 동네 피해와 개별 집의 상태를 구분합니다.

동네 피해 관측 · 우리 집 상태 미확인

시연 자료에는 집 단위 대조 근거가 없습니다. 상세 주소는 기본적으로 등록자에게만 보입니다.

실행 방법

  1. Windows에 Node.js 22 이상을 준비합니다.
  2. 결과물 ZIP을 풀고 start.cmd를 실행합니다.
  3. 브라우저에서 127.0.0.1:4173을 엽니다.
  4. 일반 창에서 서연, 다른 프로필이나 시크릿 창에서 지우로 들어갑니다.
결과물 내려받기

시연할 흐름

기록 후 버리기 또는 공유 선택
오프라인 음성 기록과 연결 복구
다른 가족 화면에서 수신 확인
기간별 내보내기와 집 주변 관측 확인

첫 실행은 FFmpeg와 음성 인식 모델을 내려받으므로 인터넷이 필요합니다. 두 계정은 일반 탭 두 개가 아닌 서로 다른 브라우저 프로필로 엽니다.

구현 구조

브라우저의 MediaRecorder로 기록하고, 사용자가 보관 또는 공유를 선택하면 IndexedDB에 저장합니다. Node.js 서버가 로그인과 가족 공간 접근을 확인합니다. FFmpeg가 미디어 파일을 합치고, whisper.cpp가 업로드한 음성을 글로 옮깁니다.

시연 범위와 남은 검증

해커톤 시연용 구현이며 실제 피란 가족을 대상으로 사용성을 검증하지 않았습니다. 종단간 암호화와 운영 환경의 보안 검토는 완료하지 않았습니다. 휴대전화에서 촬영·녹음하려면 브라우저가 신뢰하는 HTTPS 주소가 필요합니다.
